# 长夜邮差 · The Long Night Post

一款在小星球上行走的第三人称叙事探索游戏。长夜季来临前，发条邮差“嘀嗒”要把最后几封信送到小星球上，每送到一封，那颗星的邮灯就会亮起来。

故事、角色、星球、模型和配乐全部是原创的。这一版用 Unity 6 + HDRP 重做了画面，目前可以玩第一站“发条屿”，其余几站还在移植。

## 下载

到 [Releases](https://github.com/Air-Sage/long-night-post-play/releases/latest) 下载 `LongNightPost-mac.zip`，解压得到 `LongNightPost.app`。

**第一次打开**：这个程序没有苹果开发者签名，直接双击会被拦下。在 Finder 里按住 Control 点按 `LongNightPost.app`，选“打开”，再点“打开”。如果还是打不开，到“系统设置 → 隐私与安全性”，在页面底部点“仍要打开”。之后就能正常双击了。

**配置**：macOS 12 或更新，Apple 芯片和 Intel 都能运行；画面比较吃显卡，建议 M1 或更新的 Mac。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动 |
| 鼠标 | 转视角 |
| Shift | 快跑 |
| 空格 | 跳 |
| E | 互动 / 推进对话 |
| Esc | 暂停（R 重来本站，L 切换中英文，Q 退出） |
| F2 | 切换到材质与光影展台（看模型用），再按一次回到游戏 |

也支持手柄。

## 素材

模型和材质由 Blender 脚本生成；扫描贴图来自 [Poly Haven](https://polyhaven.com)（CC0）；界面文字用的是 macOS 自带字体；音乐和音效由程序合成。
